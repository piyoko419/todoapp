# Google Meet 出席自動集計ツール

Google Meet で実施しているプログラムの出席管理を自動化する Google Apps Script です。

## 解決する課題

| 現状(手作業) | このツール導入後 |
| --- | --- |
| 講師が画面の参加者を目視で数えて手入力 | Meet が記録している参加者データを毎日自動取得 |
| 月次の集計が手作業 | 月次サマリーを自動生成 |
| リピート率の集計が手作業 | 新規/リピーター/リピート率を自動計算 |

Google Meet は会議ごとに「誰が・いつ入室し・いつ退出したか」を記録しており、
**Google Meet REST API** でその記録を取得できます。このスクリプトは毎日それを
スプレッドシートに取り込み、集計シートを更新します。**講師の操作は一切不要**になります。

## 生成されるシート

1. **参加ログ** — 1行 = 1人 × 1回の会議。日付・会議コード・参加者名・入退室時刻・滞在時間(分)
2. **月次サマリー** — 月ごとの 開催回数 / 延べ参加者数 / ユニーク参加者数 / 新規参加者数 / リピーター数 / **リピート率** / 平均参加者数
3. **参加者マスタ** — 参加者ごとの 初回参加日 / 最終参加日 / 参加回数 / 参加月数

### リピート率の定義

> その月のユニーク参加者のうち、**それ以前の月にも参加したことがある人**の割合

(= リピーター数 ÷ ユニーク参加者数。定義を変えたい場合はご相談ください)

## 前提条件

- **会議を主催(作成)しているアカウント**でこのスクリプトを実行すること。
  Meet API は自分が主催した会議の参加者記録のみ取得できます。
- 無料の Google アカウントでも Google Workspace でも動作します。
  録画や文字起こしの取得には Workspace が必要ですが、本ツールが使う
  参加者記録(入退室時刻)の取得に Workspace は不要です。
- 参加者データは**会議終了後**に生成されます(進行中の会議は次回の同期で取り込まれます)。

## セットアップ手順(約10分・初回のみ)

1. [Google スプレッドシート](https://sheets.new) を新規作成し、名前を付ける(例: `Meet出席管理`)
2. メニュー **拡張機能 → Apps Script** を開く
3. エディタに表示されている `コード.gs` の中身を全て消し、この `Code.gs` の内容を貼り付けて保存
   (GitHub では「Raw」ボタンで開いてから全選択コピーすると確実です)
4. エディタ左側の歯車アイコン **「プロジェクトの設定」** を開き、
   **「『appsscript.json』マニフェスト ファイルをエディタで表示する」にチェック** を入れる
5. 左側の **「エディタ」(< > アイコン)** に戻ると `appsscript.json` というファイルが
   表示されるので、中身を全て消してこのフォルダの `appsscript.json` の内容を貼り付けて保存
   (Meet の参加記録を読むための権限をスクリプトに宣言する設定です)
6. `コード.gs` を開き、上部の関数選択で `syncAttendance` を選び **実行** →「承認が必要です」と
   出るので、会議を主催しているアカウントで **許可** する
   (「このアプリは Google で確認されていません」と出た場合は「詳細」→「(プロジェクト名)に移動」)
7. 実行が終わるとシートに過去90日分の参加記録と集計が入ります
8. 最後に関数 `setupDailyTrigger` を一度実行 → **毎朝6時台に自動同期**されるようになります

以降は何もしなくても、スプレッドシートを開けば最新の出席状況と月次集計が見られます。

## 日常の使い方

スプレッドシートを開くとメニューバーに **「Meet出席」** が追加されます。

- **今すぐ同期** — 会議直後などに手動で最新データを取り込みたいとき
- **集計だけ更新** — 参加ログを手で修正した後に集計へ反映したいとき
- **毎日の自動同期を設定** — トリガーの再設定

## 設定のカスタマイズ

`Code.gs` 冒頭の `CONFIG` で変更できます。

```js
const CONFIG = {
  LOOKBACK_DAYS: 90,                  // 初回同期で遡る日数
  MEETING_CODES: ['ust-ndqc-kwk'],    // 集計対象の会議コード。[] にすると主催した全会議が対象
  MIN_MINUTES: 0,                     // 例: 10 にすると10分未満の滞在は出席にカウントしない
};
```

会議コードは Meet の URL 末尾(`https://meet.google.com/ust-ndqc-kwk` の `ust-ndqc-kwk`)です。
別の会議も集計したい場合は `MEETING_CODES` に追加してください。

## 注意点・制限事項

- **参加者の識別**: Google アカウントでログインして参加した人はアカウントIDで確実に
  同一人物として追跡されます。**ログインせず名前入力だけで参加した人は表示名で識別**する
  ため、「山田」「山田太郎」のような表記ゆれがあると別人としてカウントされます。
  → 参加者にはログインして参加してもらうのが確実です。
- **滞在時間**は「最初の入室〜最後の退出」で計算しています(途中退席して戻った場合、
  離席時間も含まれます)。
- 過去の会議データをどこまで遡れるかは Google 側の保持期間に依存します。
  導入後のデータは毎日取り込まれるため確実に蓄積されます。

## 参考: Google Workspace をお使いの場合の代替手段

Google Workspace(Business Standard 以上 / Education)には、会議終了後に主催者へ
出席レポート CSV がメールで届く「出席状況の確認」機能があります。ただし月次集計や
リピート率の計算は結局手作業になるため、その場合でも本ツールの併用をおすすめします。
