# LINE 連携のセットアップ

LINE 公式アカウントをこれから作る前提の手順です。
**LINE を設定しなくても Web 画面（取り込み・ボード・スタッフ画面）はそのまま使えます。**
設定すると、そこに「LINE への通知」と「LINE からの受諾・完了報告」が乗ります。

---

## 1. LINE 公式アカウントと Messaging API チャネルを作る

1. [LINE Official Account Manager](https://manager.line.biz/) でアカウントを作成（無料のコミュニケーションプランで足ります）。
2. [LINE Developers](https://developers.line.biz/console/) にログインし、プロバイダーを作成。
3. 作成したプロバイダーで **Messaging API チャネル** を作る（既存の公式アカウントと連携する形でも可）。

## 2. トークンを取得して `.env.local` に書く

LINE Developers のチャネル設定画面から次の 2 つを取得します。

| 取得場所 | 環境変数 |
| --- | --- |
| 「チャネル基本設定」> チャネルシークレット | `LINE_CHANNEL_SECRET` |
| 「Messaging API設定」> チャネルアクセストークン（長期） | `LINE_CHANNEL_ACCESS_TOKEN` |

```bash
cp .env.example .env.local
# .env.local を編集して 2 つの値を貼り付ける
```

## 3. Webhook URL を登録する

「Messaging API設定」>「Webhook URL」に、公開した URL + `/api/line/webhook` を設定します。

```
https://<あなたのドメイン>/api/line/webhook
```

- 「Webhookの利用」を **オン**
- 「応答メッセージ」を **オフ**（自動応答が邪魔をするため）
- 「あいさつメッセージ」は任意

ローカルで試すときは [ngrok](https://ngrok.com/) などでトンネルを張り、
`https://xxxx.ngrok.io/api/line/webhook` を登録してください。

> 署名は `LINE_CHANNEL_SECRET` で検証しています。署名が合わない POST は 401 で拒否します。

## 4. スタッフ・依頼元を登録する

公式アカウントを友だち追加したうえで、トークルームに送信してもらいます。

| 送る内容 | 登録される役割 |
| --- | --- |
| `スタッフ登録 山田太郎` | スタッフ（案件の受諾・完了報告ができる） |
| `依頼元登録 相談室くわん` | 依頼元（LINE から依頼を送れる） |

登録結果は案件ボード画面の「スタッフ」欄でも確認できます。

## 5. スタッフ用グループに一括通知する（任意）

スタッフ全員のグループに公式アカウントを招待し、そのグループ ID を
`LINE_STAFF_GROUP_ID` に設定すると、新規案件をグループ 1 箇所に流せます。

グループ ID は、グループ内で何か発言したときに Webhook へ届く
`source.groupId` をサーバーログから拾うのが手軽です。
未設定の場合は、登録済みスタッフ個人あてのマルチキャスト送信になります。

## 使えるコマンド

### スタッフ

| 送る内容 | 動き |
| --- | --- |
| `一覧` | 未完了の案件をカードで返す |
| `今日` | 本日が期限または実施予定の案件 |
| `担当` | 自分が担当している案件 |

カードのボタンで `この案件を受ける` → `作業開始` → `完了報告` まで進みます。
ボタンは現在の状態に応じて、次に押せるものだけが出ます。

### 依頼元

依頼内容をそのまま送ると、部屋番号・時期・清掃内容を読み取って受付します。

```
231・233・308・322・338号室

【時期】
338号室→至急
233・308・322号室→9月中
231号室→なるべく早めに

【清掃内容】
231・233・308・322号室→通常の清掃のみ
338号室→プラス剥離
```

受付後、確認メッセージが依頼元に返り、スタッフ側に新規案件が流れます。

## リッチメニュー（任意）

LINE Official Account Manager >「リッチメニュー」で、
`一覧` `今日` `担当` をテキスト送信するボタンを並べておくと、
スタッフが文字を打たずに操作できます。

## うまく動かないとき

| 症状 | 確認すること |
| --- | --- |
| Webhook が届かない | 「Webhookの利用」がオンか、URL の末尾が `/api/line/webhook` か |
| 401 が返る | `LINE_CHANNEL_SECRET` がチャネルのものと一致しているか |
| 通知が飛ばない | サーバーログの `[line]` 行。403 ならアクセストークンを再発行 |
| 自動応答が混ざる | 「応答メッセージ」をオフに |
